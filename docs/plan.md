# Payroll Protect V2 — discovery answers + art direction plan

Date: 2026-10-18. Status: awaiting approval.

## Discovery (pre-filled from brand files + live V1 site)
1. Business: Payroll Protect, UK construction payroll verification. Biometric site-entry attendance matched line by line against subcontractor labour invoices; unverified lines flagged before payment.
2. Customer: finance directors, commercial managers, heads of payroll at housebuilders, Tier 1 and infrastructure contractors. Care about: margin leakage, defensible audit trail, zero disruption on site.
3. One action: book a 90-day pilot (form → hello@payrollprotect.co.uk).
4. Tone: direct, calm, evidence-led. Technical and precise, with site grit.
5. Assets: logo found (Downloads, P-shield version; web sizes made in site/assets/brand). Colours #0FD76A / #232323. Fonts: none specified → Archivo + Inter. Photos: none → generate with Higgsfield.
6. Pages: one long-scroll homepage (calculator and booking form built in) + privacy page stub. V1's separate Audit Tool page folds into the Numbers section.
7. Domain: payrollprotect.co.uk (V1 live there; V2 replaces it).

## Palette
- Neutral: #F4F4F2 (concrete white)
- Dark: #161616 page dark / #232323 brand charcoal for text
- Accent: #0FD76A brand green (hover #0BBE5D). Dark text on green buttons (contrast 8.5:1).
- Support: rule #E2E3DE, muted text #6B6F6A

## Type (Google Fonts)
- Display: Archivo (variable width; extended caps for eyebrows echo the "PROTECT" wordmark, weight 700–800 for headlines)
- Body: Inter

## Scroll hero concept (3 options)
A. "Access granted" (recommended) — dawn at a site gate; biometric terminal on a hoarding post, screen dim. As you scroll a worker in hi-vis (seen from behind, no face) steps up and the screen turns brand green with a tick, green light spilling onto wet ground. One slow push-in. Grey → green = unverified → verified.
B. "The line clears" — top-down macro over a labour invoice on a site desk; green sweeps down the lines, one line stays amber. Risk: text in frame, abstract.
C. "Site wakes up" — slow aerial rise over a housebuilding site, blue hour to sunrise. Beautiful but generic; every contractor uses drone shots.
